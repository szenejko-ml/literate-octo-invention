# Aggregate results overview

This file summarizes public-safe, aggregate/model-level outputs from the manuscript extension. Participant-level clinical data are not included.

## Primary cohort

- Primary cohort: `all_years_shared`
- N = 13,649
- Euploid = 13,438
- Non-euploid = 211
- Performance source: held-out outer-fold OOF predictions only

## Manuscript extension

The extension is post-hoc and does not retrain the base estimators or change the locked OOF thresholds. It includes:

- age, baseline-risk and diagnosis subgroup summaries;
- paired reclassification analyses;
- error-structure analyses;
- global SHAP analyses;
- SHAP stability analyses;
- surrogate-tree fidelity analyses;
- predictor-complete cohort sensitivity;
- clinical-indication / override audit.

## Public-data boundary

The source workbook contains a sheet named `SHAP_local_false_reass` with participant-level pseudonymous `record_id`, diagnosis, fold-specific probabilities and local SHAP values for false-reassurance cases. That sheet is intentionally **not** published in this public repository.

Clinical source data, participant-level OOF predictions, private audit files and fitted `.joblib` artifacts are also excluded.

A public-safe workbook can be generated by removing the participant-level local-SHAP sheet while retaining the aggregate/model-level result tables.
